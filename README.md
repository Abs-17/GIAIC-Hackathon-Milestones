# GIAIC Hackathon Milestones

Three progressively advanced resume-building projects built during the **Governor Initiative for Artificial Intelligence (GIAIC)** hackathon. Each milestone extends the previous one — from a static interactive resume to a fully editable dynamic builder.

---

## Milestones

### Milestone 01 — Interactive Resume
A personal resume built with HTML, CSS, and TypeScript — structured, styled, and interactive.

**What it does:**
- Displays a clean, formatted personal resume in the browser
- Interactive UI elements built with TypeScript
- Foundation for the dynamic versions in later milestones

**Stack:** HTML · CSS · TypeScript

---

### Milestone 02 — Dynamic Resume Builder
A step up from M1 — users can now input their own data and generate a formatted resume dynamically.

**What it does:**
- Form-based input for personal info, education, skills, experience
- Dynamically renders a formatted resume from user input
- No page reload — real-time generation

**Stack:** HTML · CSS · TypeScript · JavaScript

---

### Milestone 03 — Editable Resume Builder
The most advanced version — users can directly edit resume content inline, without needing a separate form.

**What it does:**
- All resume fields are directly editable in the rendered resume itself
- Changes reflect instantly without any form submission
- Closest to a real-world resume editor experience

**Stack:** HTML · CSS · TypeScript · JavaScript

---

## What I learned

- How to progressively improve a project across iterations
- TypeScript for structured, type-safe frontend logic
- Dynamic DOM manipulation and real-time content editing
- Building user-facing tools that solve a real problem (resume creation)

## About GIAIC

The **Governor Initiative for Artificial Intelligence (GIAIC)** is a Pakistan-based program teaching modern AI, web, and automation skills. This hackathon was part of the program curriculum.
